# Somaia Mohamed — Self-Contained GitHub Pages Website

This package is built so the website does NOT depend on an `assets/` folder.

Every HTML page contains:
- the full CSS
- the JavaScript
- the logo and Qatar images embedded directly in the page

## Publish to GitHub Pages

1. Extract this ZIP.
2. Upload everything inside it to the ROOT of your GitHub Pages repository.
3. Keep the `ar` folder exactly where it is.
4. Keep `index.html` in the repository root.
5. In GitHub: Settings → Pages → deploy from your selected branch/root.

English:
- `index.html`

Arabic:
- `ar/index.html`

Also included:
- `robots.txt`
- `sitemap.xml`

No `assets` folder is required.
