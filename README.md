# Somaia Mohamed — Final GitHub Pages Website

## Publishing model
English is the MAIN / canonical version at the repository root.

- `/index.html` → English Home
- `/about.html` → English About
- `/services.html` → English Services
- `/case-studies.html` → English Case Studies
- `/blog.html` → English Blog
- `/contact.html` → English Contact

Arabic is the secondary version under `/ar/`.

## Design
- Qatar evening photo is integrated into the composition with fades, masks, orbit lines and layered motion.
- User-provided Somaia Mohamed logo is built into the header, hero and footer.
- Responsive desktop/tablet/mobile layouts.
- Scroll reveal, hover motion, floating logo, orbit animation, subtle parallax and card tilt.
- Premium serif/sans typography with Arabic RTL styling.

## GitHub Pages
Extract this ZIP and upload the CONTENTS to the ROOT of the GitHub Pages repository.

There is intentionally NO assets folder dependency. CSS, JS and images are embedded in the HTML pages, so the styling cannot disappear because of a broken relative path.

Google Fonts are optional; if unavailable, the site falls back to local system fonts.

## WhatsApp
The visible site uses “WhatsApp Me” / “تواصل معي” and does not display the phone number as text.
