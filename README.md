# Sm.Digital marketing.qa — optimized static site

This version is prepared for GitHub Pages.

## Structure
- English: `/`
- Arabic: `/ar/`
- Shared CSS: `/assets/style.css`
- Shared JS: `/assets/script.js`
- Sitemap: `/sitemap.xml`
- Robots: `/robots.txt`

## Deploy
Upload the contents of this folder to the root of the `smdigitalmarketing.github.io` repository. Do not upload the ZIP itself.

## Notes
- Google Search Console verification is included in the `<head>` of the pages.
- Floating WhatsApp Contact button is included site-wide.
- English and Arabic pages cross-reference each other with hreflang.
